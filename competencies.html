Technical

Coding & Code Quality

Tech Lead focus: quality across project/team, maintainability, scalability, reviews and mentoring.

Answer: Pre-commit validation → manual + AI review → release impact review.

Evidence: PHPCS/unit tests, Cursor rules, Python release-review workflow.

Testing & QA

Define and maintain the project testing approach, review completeness and cover cross-module impact.

Change → dependency → impact → test.

Debugging & Troubleshooting

Support multi-module and production troubleshooting using logs, monitoring, traces, database and system signals.

Impact → evidence → affected layer → action/support → verify.

Observability

Use monitoring and logs to understand behavior, support issue analysis, reproduce difficult defects and verify changes.

Software Design & Architecture

Evaluate module integration and trade-offs across scalability, maintainability and performance.

Requirement → options → trade-off → decision → verify.

Security

Input handling, authorization, sensitive data, dependencies and secure release controls.

AI-Assisted Development

Guide project-level use of AI while keeping code quality, security and human validation in the workflow.

Prompt Engineering & Workflow Design

Use fixed structure, project skills and structured outputs for repeatable workflows.

AI Quality & Compliance

Ground in source artifacts, review hallucinations, protect credentials and keep final approval human.

Data Management

Review queries, schema, indexes, integrity and performance using evidence before proposing changes.

Certifications

State current status factually and only give a timeline when there is a defined plan.
